# GNK ASG Mail Fix 2026-06-21

Ovaj paket objedinjuje:

- sigurni operator token u session storageu;
- zabranu tokena u URL-u;
- sigurni admin gate za web, mobilni admin, Mail Studio i PDF Publisher;
- Mail Studio autentikaciju preko glavnog Operatora;
- vanjski outbound sloj za Resend ili Brevo;
- Cloudflare EMAIL binding samo za interne odobrene destinacije;
- Contact API V4 s internom obavijesti, KV/D1/R2 evidencijom i vanjskim autoresponderom;
- urednu potvrdu na kontakt stranici umjesto prikaza sirovog JSON-a.

Obvezni Cloudflare secret za stvarnu dostavu vanjskim primateljima:

- `RESEND_API_KEY`, ili
- `BREVO_API_KEY`.

Bez jednog od ta dva secreta upiti se evidentiraju i interna obavijest može raditi, ali vanjski primatelji neće dobivati poruke.

Worker konfiguracije:

- `workers/gnk-asg-mail-agent-worker/wrangler.release.toml`
- `workers/gnk-asg-contact-api/wrangler.toml`
