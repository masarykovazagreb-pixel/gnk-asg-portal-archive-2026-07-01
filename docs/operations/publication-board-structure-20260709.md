# Publication board structure — draft

This document defines the content structure only. Final publication approval rules are to be agreed later.

Categories:
- articles
- statements
- financial proposals
- reports
- texts for review
- ready for publication

Status values:
- draft
- in-review
- legal-check
- finance-check
- ready
- approved
- published
- rejected
- on-hold

Required fields:
- title
- category
- author worker
- source function
- summary
- risk level
- legal check
- finance check
- recommended action
- target route
- approval status
- published URL

Safety principle:
- no publication is treated as automatically approved by this structure;
- final approval rules remain separate.
