# EXA research — AKTUAL MEDIA free global expansion (2026-10-22)

## Verified official constraints

1. Cloudflare Pages Free: **100 projects per account, 500 builds/month, 1 concurrent build, 20,000 files/site, 25 MiB/file, 100 custom domains/project**; actual project capacity on our specific account must be read before any new project is created. [Cloudflare official Pages limits](https://developers.cloudflare.com/pages/platform/limits/) (last updated September 5, 2026).
2. Static asset requests on Pages are free and unlimited, while Pages Functions consume Workers requests (**Workers Free and Pages Functions share 100,000 daily requests**). Use static HTML and owned assets for global editions. [Cloudflare official Pages Functions pricing](https://developers.cloudflare.com/pages/functions/pricing/) (updated September 8, 2026).
3. Cloudflare Pages supports GitHub integration and PR preview URLs. Preview is not canonical production publication; release remains behind repository guardrails. [Official GitHub integration](https://developers.cloudflare.com/pages/configuration/git-integration/github-integration/) (updated October 15, 2026).
4. Google recommends unique URL per language version, local-language **visible main content**, accessible language switching, and `hreflang` on equivalent real editions. `<html lang>` alone does not establish language detection; translations of just the template provide poor value. [Google international multilingual documentation](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites).
5. Google policies prohibit **doorway abuse**: thin, near-identical city/region portals that merely funnel readers to a central site, as well as keyword stuffing and link spam. Each edition needs verifiable independent user value: locally sourced original analysis and clear editorial status; not autogenerated mirrors to manufacture backlinks. [Google spam policies](https://developers.google.com/search/docs/essentials/spam-policies).
6. GitHub Actions standard GitHub-hosted runners are free in public repositories; private repositories consume quota. GitHub Free baseline is **2,000 included minutes/month** for private-repo standard runner use, but GNK ASG intentionally retains an internal **1,000-minute/month guard** until actual repository visibility, plan and account use are verified. [GitHub official Actions billing](https://docs.github.com/en/billing/managing-billing-for-github-actions/about-billing-for-github-actions).

## Concrete changes to apply when implementing international publication

- Preserve **one authoritative set** of **12** world edition IDs from `config/control-plane/world-free-portal-network-v1.json`. Other staging layout/design variants must not trigger duplicate live sites.
- Remain within current existing **4-hour orchestration**, not a new hourly cron; 150 shared runner roles are tasks, **not** 150 deployed Cloudflare Workers.
- Keep every draft global site `noindex,nofollow,noarchive` and **no inferred canonical from proposed pages.dev host**. Once actually deployed, verify per-site HTTP 200, validated project hostname, readable localized body, origin SHA, owned/licensed visuals; only then determine a real canonical and possible indexing approval.
- For cross-country equivalent, independently verified translated articles, add reciprocal `hreflang` including correct country language subtags; do not attach `hreflang` to distinct, unrelated articles just because they share a brand.
- Keep official-source feed collector read-only; no mass automated article scraping, copyrighted full-text reproduction, unverified source images, fake personal authorship or automatically created backlink farms.
- Avoid merging or public production changes until green mandatory CI and exact-SHA authorized release. The existing repository security gate deliberately rejects new arbitrary production deploy actions; `.github/workflows/aktual-world-free-release.yml` is a *read-only staging handoff*, not deploy.
- Existing Editorial Approval page stores some decisions client-side; do not start production release timers based solely on local browser state. Server-side decision ledger, verified notice delivery, immutable source hash and scoped 30-minute clock required.

## Low-cost prioritized experiments

1. Publish **one** high-quality native-language example article in staging for two clearly different pilot markets; attach 2+ verifiable public citations and self-produced/licensed visual assets; editorial HOLD until reviewed.
2. Compare results (indexing, referral engagement, usability, publication incidents) before launching remaining portals. Use canonical hub links for navigation, not link manipulation.
3. Audit 15 national and eight regional sources by source URL, age and parser error; prioritize source health before increasing output frequency.
4. Measure build usage, Pages project count, Actions consumption, and site HTTP receipts; pause before exhausting free tier.

**Research surface:** Exa search queries covered Cloudflare official quotas, Google multilingual SEO/spam, GitHub Actions billing and alternative free static providers. Official documentation is preferred over third-party rankings. This document is evidence and plan, not a live-deployment receipt.
