# Daily worker reporting structure — draft

This document defines structure only. Final operating rules, deadlines, silence/acceptance rules, and approval authority are to be agreed later.

Daily report functions:
- Finance
- Publications
- Newsroom
- Legal
- Media
- Mail Studio
- Campaign
- Security

Required report fields:
- date
- function
- owner / worker group
- summary
- completed checks
- risks
- items ready for review
- items on hold
- recommendations
- approval status

Status values:
- draft
- in-review
- ready
- approved
- published
- rejected
- on-hold

Safety principle:
- workers prepare and route;
- no autonomous mail sending;
- no autonomous campaign launch;
- no autonomous production deploy;
- final rules to be agreed separately.
