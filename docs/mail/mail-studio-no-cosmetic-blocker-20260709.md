# No cosmetic blocker rule — 2026-07-09

Mail Studio functionality must not be blocked by cosmetic portal work.

## Rule

If the full public portal visual upgrade is not ready, Mail Studio can still be advanced as the minimum operational deliverable, provided the existing safe workflow passes and the live route checks remain green.

## Non-negotiable controls

- authenticated access
- v27 runtime
- gold-logo signature
- mandatory BCC
- individual send only
- audit/dedupe
- no bulk campaign enablement
