- Hotelski smještaj je već osiguran i plaćen.
- Odobreni letovi i lokalni transferi plaćaju se kroz prethodno odobren postupak.
- Karte se ne kupuju samostalno prije pisanog odobrenja.

- Executive Working Lunch održava se na lokaciji glavne prezentacije.

- Točne lokacije i identiteti kompanija ostaju povjerljivi do odgovarajućeg trenutka.
- Kopije putovnica i drugi osjetljivi dokumenti ne šalju se običnim e-mailom.
- Svaka pozvana redakcija mora dobiti vlastitu šifru poziva i vlastiti pristup aplikaciji.
