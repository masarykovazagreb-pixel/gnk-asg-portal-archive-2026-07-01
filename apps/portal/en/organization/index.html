Register of companies and codes

Companies, job-position codes and Group hierarchy.

This register shows the coding system the Group uses in internal and public communication (e.g. with media), so it is clear who is responsible for a given area without disclosing information that is not yet ready for publication.

How to read this page

A full name is publicly stated only for Nermin Sefić (Group CEO and Director of GNK ASG d.o.o.) — the only formally confirmed and publicly named person on this register. Every other position is shown as a code template with an [NAME] and [S] (first letter of surname) field — these are placeholders for future appointments, not real people. When a position is formally filled, that one row receives a real name; the rest of the register remains a template until the same process is completed for them too.

Coding system

Personal code format.

A unique code consists of: the Group marker, the company code, a name (or the [NAME] placeholder), first letter of surname (or [S]), and a standardised function label.

GNK-[COMPANY]-[NAME]-[S]-[FUNCTION]
