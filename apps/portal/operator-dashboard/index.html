Prijava

Unesite operator token. Izbornici mailova i potpisi sada postoje lokalno odmah, a backend se koristi za slanje i spremanje.

Ako status endpoint ne prođe, UI i dalje prikazuje mail adrese i potpise. Slanje maila traži ispravan operator token i aktivan operator API.
