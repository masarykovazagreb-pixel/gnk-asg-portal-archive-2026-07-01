Kako se pokreće

  1. Pritisnite Ručno pokreni vijesti.
  2. Na GitHub stranici prijavite se svojim ovlaštenim računom, ako je potrebno.
  3. Odaberite Run workflow i potvrdite ponovno Run workflow.
  4. Vratite se ovdje i pritisnite Provjeri status sada.

Sigurnosno pravilo: ova zasebna kontrola ne sadrži GitHub token, lozinku niti pravo izravnog pisanja u repozitorij.
