# GNK ASG Media Kit source package

Status: **release candidate pending user approval**.

This directory contains controlled, audit-ready sources for:

1. GNK ASG d.o.o. Media Kit
2. GNK DINAMO Ltd. Media Kit
3. GNK ASG / GNK DINAMO Ltd. Corporate Information Pack

The source package is intentionally not exposed as an approved public ZIP/PDF download. The package workflow validates exact legal names, prohibited claims, controlled-release notices and SHA-256 integrity before producing review artifacts.

No source file may be described as final or production-approved until the user approves the package and the approved checksums are recorded.
