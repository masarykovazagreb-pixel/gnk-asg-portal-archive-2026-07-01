Executive summary

Ne jedna transakcija, nego aktivacija arhitekture.

Najvažniji program

Što je THE CODE?

THE CODE je istodobno kodno ime projekta, poslovna arhitektura, integracijski sustav i službeni trenutak objave međunarodnog akvizicijskog procesa. Dokumentacija ga opisuje kao program koji ulazi u svakodnevni život, infrastrukturu i poslovanje — automobil, dom, cestu, grad, podatke, usluge i sustave koje ljudi već koriste.
