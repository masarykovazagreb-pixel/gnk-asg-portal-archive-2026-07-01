THE CODE · Official media registration

Registracija redakcije i siguran pristupNewsroom registration and secure access

Novi media korisnik kreira zasebno korisničko ime i lozinku, unosi službeni e-mail i naziv redakcije te odmah otvara puni obrazac. Istim korisničkim imenom i lozinkom kasnije se ponovno prijavljuje i nastavlja spremljeni nacrt. Ovaj račun služi samo za media prijavu i ne daje admin pristup.

A new media user creates a dedicated username and password, enters an official email address and newsroom name, and immediately opens the full application. The same username and password are used later to sign in and continue the saved draft. This account is only for the media application and does not grant admin access.
