Pre-release checklist

  • All review pages render on desktop and mobile.
  • Every public claim has an approved source and status.
  • Manual, batch and automatic mail paths show exactly one correct signature.
  • No test message is sent to an external recipient.
  • Backup, recovery reference and rollback owner are confirmed.
  • Final diff excludes DNS, routes, secrets and locked production entry points.

Post-release verification

  • Canonical homepage and English homepage return expected content.
  • Protected admin and mail routes remain protected.
  • Mission Control and review modules return expected status.
  • Mail status, campaign validation and logs remain available.
  • Rollback is initiated immediately on material regression.
