Access separation

  • Javno: /media-application/?lang=en ostaje dostupan redakcijama bez admin tokena.
  • Zaštićeno: pregled, detalji, dokumenti, audit i odluke dostupni su samo kroz postojeću admin sesiju.

  • Mission Control prikazuje samo zbirne podatke, ne osobne podatke prijavljenih osoba.

Truth rules

  • Repository presence nije runtime dokaz.
  • Statička ili CI provjera nije dokaz stvarne isporuke maila ili javne objave.
  • THE CODE Intelligence ne zamjenjuje originalni THE CODE projekt.
  • Automatski pripremljen nacrt nije automatski odobrena objava.
  • Nermin Sefić navodi se kao autor samo kada je autorstvo ili komentar potvrđen.
  • Konačna odluka ostaje u Executive Officeu.
