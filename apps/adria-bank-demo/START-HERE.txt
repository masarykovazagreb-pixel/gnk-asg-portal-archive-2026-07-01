ADRIA BANK DEMO 1.2.0 — SOURCE/DEVELOPER BUNDLE

This is the legacy source bundle, not the easy end-user installer. To install the Windows 11 desktop app without Node.js or npm, use the separate standalone Windows installer ZIP linked in `DOWNLOADS.md`; it contains `Adria-Banka-Demo-Setup-1.2.0-x64.exe` and its SHA-256 checksum.

For this source bundle only:
1. Extract it to a writable folder.
2. Install Node.js 22.12 or newer (64-bit) and npm; keep normal TLS/certificate verification enabled.
3. Double-click `START-ADRIA-BANK-DEMO.bat`. First-time setup needs internet to download npm packages and Electron. It installs per-user and creates Desktop/Start-menu shortcuts.

If source setup fails, read the PowerShell error and ask an administrator to configure the approved certificate chain. Do not disable TLS verification or Windows security protections. This source-based setup is not a standalone `.exe` installer.

The app is a fictional local rehearsal only. It is not a bank, financial service or exchange; it does not open real accounts, verify identity, authorize cards, transmit payments or trade. Use synthetic records only. Optional public reference rates may require internet; the local scenario has clearly labelled sample data.

Desktop demo version — not a real bank or financial service.
