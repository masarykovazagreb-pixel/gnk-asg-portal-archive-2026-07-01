# GNK ASG One Page V1

Clean, isolated one-page portal.

## Editing model

- `site.config.json` — all text, metrics, links, locations, news, publications and contact settings.
- `styles.css` — visual system and responsive layout.
- `app.js` — rendering, language switch, mobile menu and contact submission.
- `index.html` — stable shell only.

## Visual approval

No image is rendered by default. The slots `HOME-HERO-01` and `HOME-NETWORK-03` remain placeholders until the exact asset and crop are explicitly approved.

## Isolation

This project does not import any legacy public menu, V13/V28 layout patch, index lock, gallery injector or old HTML transformer.
