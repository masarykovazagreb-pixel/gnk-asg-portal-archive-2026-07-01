# GNK ASG Portal

Privatna razvojna baza za GNK ASG portal i povezane Cloudflare Workere.

## Struktura

- apps/portal — aktivni HR/EN frontend
- workers — aktivni Cloudflare Workeri bez secrets
- packages — budući zajednički UI, navigacija, API, SEO i teme
- contracts — rute, endpointi i bindings
- docs — arhitektura i projektna dokumentacija

Produkcija gnk-asg.hr nije promijenjena.
Cloudflare deploy nije izvršen.
